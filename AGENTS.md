# Agent instructions: openclaw-vps

This repo is **public**. Commit only generic, reusable infrastructure: Terraform, install scripts, and the
HEY gateway. Keep the live deployment out of it, in commits and in issues alike: hostnames, tailnet names
and URLs, user names, IPs, schedules, household details, and security posture (firewall rules, what's
backed up). Those live in the owner's private operations docs; file tasks about the live deployment there too.
